About Conduit

Conduit exists because chatbot commands are already a real workflow. The question is whether the local bridge is explicit, inspectable, and policy-routed, or whether users keep pasting mystery text into terminals.

Local first

Conduit keeps execution on the user’s machine. Sessions, nonces, runs, policy decisions, and tool results are local state.

Consent shaped

A standalone envelope is a deliberate gesture. A paragraph containing a hidden block is not.

Agent-loop aware

The embedded parser still exists for authenticated elevated transports, where the user has opted into an agent loop.

What v0 is proving

Conduit v0 is proving the narrow loop: create a trusted session, copy an exact request envelope, execute locally through policy, rotate the nonce, and return a result block that can be pasted back into a chat.
