Copy the request. Only the request.

Conduit runs arbitrary code on your machine, and that is the point. It is not a sandbox: it decides who may ask, runs trusted sources quietly, asks once for an unknown source and refuses a replayed request.

Get Conduit Read the API

A macOS menu-bar app, plus a TypeScript CLI and control panel that also run on Linux. Clipboard capture is macOS-only for now.

Compliance mode by default.

Clipboard execution uses exact-envelope parsing. Prose, READMEs, issue comments, webpages, and chat replies that merely contain a Conduit block are text, not consent.

Exact envelopes

The daemon executes only a standalone Conduit envelope after trimming leading and trailing whitespace.

Sessions and nonces

Trusted execution requires a paired local session and a one-shot nonce bound to that session.

Policy-routed tools

Reads, writes, patches, git inspection, and shell commands flow through local profiles and confirmations.

How a request travels.

1

An agent asks

A chat model emits one fenced conduit block: schema, source, declared permissions, and stable action IDs.

2

You copy only that block

The clipboard watcher sees an exact envelope. Without a paired session it becomes a review, never a silent run.

3

Policy, then you, then results

Local policy checks roots and profiles, you approve or deny, and results come back as a block to paste into the chat.

Better than curl | sh.

Conduit does not sandbox what runs. It decides who may ask, runs trusted sources quietly, asks once for an unknown source and refuses a replayed request.
