About Conduit

Running real code on your own machine still carries a power-user tax: an installer to download, a terminal to open, setup steps to follow. Conduit aims to remove that tax so anyone can run arbitrary code with one click, no installer, no terminal. It is better than curl | sh, and it is not a safety product.

Local first

Conduit keeps execution on the user’s machine. Sessions, nonces, runs, policy decisions, and tool results are local state.

Consent shaped

A standalone envelope is a deliberate gesture. A paragraph containing a hidden block is not.

Agent-loop aware

The embedded parser still exists for authenticated elevated transports, where the user has opted into an agent loop.

What v0 is proving

Conduit v0 is proving the narrow loop: create a trusted session, copy an exact request envelope, execute locally through policy, rotate the nonce, and return a result block that can be pasted back into a chat.

Not built yet: a one-click "Start a server" flow, where a multiplayer game page offers a button that runs the game's server code as a background process on your machine with no separate download or install; an optional "run clean" mode; and a reusable package that can stay behind and age off on its own. Cleanup is the job of whoever writes the code that runs.
