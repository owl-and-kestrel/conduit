Tiny Arena

A multiplayer game your phone joins over Wi-Fi. This page cannot host it: browsers cannot accept incoming connections. Conduit runs the game server on this computer after asking you once.

Host game

Conduit will show you what it is about to run: server.mjs (sha256 ) on Conduit's own Node, accepting connections from your network. Conduit is not a safety product: approving runs this code; it does not make the code safe.

The game ends itself when the last player leaves or when you press End game.
