Download Conduit

The v0 install path is a macOS app: download the DMG, drag Conduit into Applications, then launch it from the menu bar. Conduit checks the Owl & Kestrel release channel for signed update manifests, verifies downloaded artifacts, and installs trusted updates in place.

Download for macOS Source and checksums

The DMG contains Conduit.app, an Applications shortcut, release notes, and first-launch guidance. Preview builds may still require right-click Open before macOS will launch them.

Do not enable embedded-block parsing for normal clipboard use. Compliance mode should remain exact-envelope-only unless you are deliberately testing an unsafe profile.

macOS app

The desktop app is the main install. It starts local services, shows approvals, copies agent handshakes, checks updates, and stops supervised processes when you quit.

Browser extension

The extension is optional for clipboard-only use. Alpha testers can load the packaged extension in Chrome or Brave Developer mode until the Web Store listing is ready.

Windows and Linux

Preview packages now carry launchers and platform metadata. Native tray/status shells are next, using the same approvals, health, updates, and bug-report contract.

Install

  1. Download Conduit.dmg from the latest GitHub release.
  2. Open the DMG and drag Conduit.app to Applications.
  3. Launch Conduit, then choose Open Control Panel from the menu-bar icon.
  4. Load the browser extension only if you want paired ChatGPT transport.

Browser Extension Alpha

The extension is a temporary developer-mode package until the Chrome Web Store account and unlisted listing are ready. If Conduit is installed, use the Conduit link to prepare the package through the same local review flow as any other request.

Prepare extension with Conduit

{
  "schema": "conduit.request.v1",
  "source": {
    "kind": "conduit-link",
    "trust": "untrusted",
    "publisher": "owl-kestrel",
    "domain": "owlandkestrel.com"
  },
  "permissions": [
    {
      "kind": "browser-extension",
      "scope": "conduit-alpha",
      "access": "prepare"
    }
  ],
  "title": "Prepare Conduit Bridge extension alpha install",
  "description": "Downloads the Conduit Bridge alpha extension package, extracts it, and opens Chrome extension settings.",
  "actions": [
    {
      "id": "prepare_extension_alpha",
      "tool": "conduit.extension.prepareAlphaInstall",
      "args": {
        "url": "https://owlandkestrel.com/releases/conduit/conduit-bridge-extension.zip"
      },
      "reason": "Prepare optional browser extension for paired ChatGPT transport.",
      "risk": "low"
    }
  ],
  "resultMode": {
    "transport": "app",
    "format": "markdown"
  }
}

Manual source checkout fallback:

npm run extension:package
unzip dist/extension/conduit-bridge-extension.zip
  1. Open chrome://extensions/ in Chrome or Brave.
  2. Enable Developer mode.
  3. Choose Load unpacked and select the unzipped conduit-bridge-extension folder.
  4. Reload your ChatGPT tab.

Build From Source

The source checkout remains the development path and can generate the same local DMG package.

npm install
npm run build
npm run macos:package
open dist/macos/Conduit.dmg
Conduit v0 is local-first and intentionally conservative by default.
